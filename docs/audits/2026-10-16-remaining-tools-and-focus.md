## Repairs and acceptance improvements

Focus Test uses ordinary artwork and output preparation, with schema 18 preserving its Z intent. Unsupported dialects, raster/non-Line overrides and contributing CNC reinterpretation cannot silently omit the focus movement. Z-feed edits preserve spatial Frame evidence while Z-offset edits invalidate it; both change executable identity. Recovery cannot infer the original physical Z after interruption and refuses line-resume for Focus programs that actually move Z, including line 1. Zero-offset output retains ordinary recovery. Normal complete Frame/Start remains available.

Multi-File Trace now forwards cancellation to its writer and checks it after asynchronous picker/name-collision waits. Cancelling before the write begins no longer starts a write after the wait returns. An already-started filesystem operation is not claimed reversible.

The final direct cancellation check paused a real batch's filename lookup, clicked **Cancel Multi-File Trace**, then resumed the lookup. The output list remained empty and the app reported **0 of 4 images were written**. The batch stress assertion was also strengthened after review: all 32 list entries must contain one SVG path, so 32 empty files cannot pass merely by sharing a hash. See the [image/AI completion report](2026-10-16-remaining-image-ai.md).

The E2E TypeScript configuration now includes TSX fixtures, with the required DOM iterable library types. A pre-existing nullable CNC fixture setting was corrected after that additional coverage exposed it. Migration assertions now include the schema 17→18 step without weakening document-preservation checks.

The first hosted CI run caught a stale installed-project qualification contract at schema 17. The contract now requires schema 18 for current saves while retaining schema 17 as an explicit historical upgrade input; malformed and future schemas remain rejected. All 31 installed-file and upgrade-qualification tests passed after the correction. This changes qualification scripts, not the application bundle used for the computer-use observations above.

The full local release-integrity run after that correction passed 786 of 787 tests. The remaining Windows NSIS test initially failed because full 7-Zip was absent. An official [7-Zip 26.04 download](https://www.7-zip.org/download.html) was extracted into ignored test artifacts, without system installation; the previously blocked test then passed, verifying real unsigned 7z payloads and rejecting disguised ZIP bytes. Its download SHA-256 is `d54bf805f9f3704d1e8db2fa3498ae7ef2df0312b40b558e7c71c734430a665d`. These are 786 passes plus one focused successful rerun, not a claim of a single green full-suite invocation. The first sandboxed attempt was interrupted after temporary evidence renames were denied (`EPERM`); the reported passes come from subsequent runs with filesystem access. Hosted Linux CI separately skips Windows-only cases and must pass before merge. Both completed local logs are preserved in the evidence manifest.

## Verification and limits

PR #1219 review identified six additional integration issues. The qualification-schema fix above also updates the canonical project schema assertion. Focus compilation errors now return the normal output-failure result in synchronous and asynchronous preparation; Preview catches unexpected synchronous failures too. Persisted sub-layer settings cannot contain `focusTest`, and normalization/materialization allow only ordinary operation settings, so relative Z intent comes exclusively from the parent operation. Job Review derives Focus warnings from compiled cut groups and the prepared device. Frame identity excludes Focus offsets on unused or unselected operations while retaining offsets on participating artwork. Air keep-alive timing follows modal G90/G91 XYZ movement, including slow symmetric Focus sweeps; M3 dark-boundary rules remain unchanged. Emitter revision `focus-relative-z-air-timing-20261016-v21` identifies the resulting output contract.

Direct browser reproduction before these fixes changed a two-sample Focus operation to Fill and clicked Preview: repeated error notifications appeared and Preview remained on “Preparing preview…”. Focused review regressions cover that failure contract, malicious schema-18 metadata, legitimate parent/subpass inheritance, selected/deleted/disabled Focus artwork, relative motion and M3/M4 air refresh. Separate review runs passed 50 distinct compilation/project/preview tests, 31 review/Frame tests, 45 air/schema tests and 12 emitter/archive tests; the runs overlap and are not added into a unique-test total. Full source TypeScript and changed-source lint passed.

The rebuilt bundle passed the same direct interaction: Fill settled to “Preview unavailable: Focus Test samples require Line mode to retain their Z-motion meaning”, with no Focus exception in the browser log. Restoring Line produced enabled route playback and a 5 s estimate. Exact 3D inspection rendered both sample lines at ±2 mm, paired returns, 54 lines, 10 segments and a 20 × 3 × 4 mm envelope.
