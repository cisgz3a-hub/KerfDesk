## Round result (2026-11-06)

All nine areas went through an auditor, a fresh refuter and a coordinator check in main's code: **46 findings raised, 0 refuted; P1 3 / P2 16 / P3 27**, plus 25 KNOWN re-observed.

**Status of fixes.** Every P1 is fixed (S1-P1-1 #1547, S1-P2-1 #1548, S4-P2-3 #1574). Every P2 from S1–S6 is fixed and merged, and so are S7-P2-1 and S7-P2-2 (#1602) and S8-P2-1's G-code-identical part (#1603). S7-P2-3 (text on a path) has fix PR #1601 open. CI was down from 2026-11-05 (repository private, then the account's Actions billing lock); the PRs merged after it went down had their required checks green from before. The P3s are being worked through in sweeps (`P3-SWEEP.md`): merged so far #1583, #1585–#1591, with the trace speed round #1594 and #1593 merged and the rest of the sweep open.

**What holds.** At ordinary sizes KerfDesk meets its budgets: Abort reaches the controller in milliseconds, streaming keeps up, the canvas runs at 60 fps at 200 objects, Save, Open and autosave are well inside budget up to 10,000 objects, peak memory at 2,000 objects is about 1 GB (better than 1.0.28 and 1.0.23), and a one-hour session leaks no DOM nodes, listeners, canvases or workers (767 created, 767 retired).

### Guards for CI

CI runners vary, so the guards count work or check boundaries rather than time:

1. **Startup download budget:** fail when the gzip size of the startup chunks grows more than 2 % over a checked-in baseline, and when a worker-only library (e.g. `linkedom`) lands in a startup chunk (S9-P3-2).
2. **Burn identity:** every performance PR keeps the golden G-code and traced-path fixtures byte-identical (already the rule; make it a required check).
3. **Work counts:** keep and extend the operation-count guards the fixes added: compiles per Preview → Frame → Start round (#1575), font parses per variable batch (#1602), histogram computations per slider step (#1578), clipper calls on the UI thread for Weld (#1582), plans per CNC export (sweep).
4. **Worker boundaries:** assert that the named heavy steps run outside the UI thread (archive, Weld check, photo decode, job preparation).
5. **Leak counts:** a 50-cycle scripted session asserting workers created equal workers retired, flat DOM node and listener counts, and bounded cache Map sizes (S9-P3-3).
6. **Timing asserts in e2e:** one shared, CI-aware helper that separates runner stalls from UI-thread blocks (#1600), strict locally.

**Maintainer decisions open:** the startup hold (S9-P3-1); the S8-P2-1 cut change (centred adaptive entry, opening long pockets; ADR-154 amendment); whether a 600 × 400 mm sign counts as ordinary for S8-P3-3.
