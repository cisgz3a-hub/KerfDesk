## Round summary (2026-10-29)

All eight areas were audited, refuted and re-verified in main's code. 52 findings were raised and none was refuted. Result: P1 13 / P2 8 / P3 31, plus 41 KNOWN.

**What 1.0.28 got right.** Every original finding re-checked here is fixed on the exact repro its report gave, and almost every regression test fails on its parent commit. These hold in full:
- #1501 (Offset keeps separate holes, all 18 join/direction combinations);
- #1505 (Fill holes, placed tabs and operation colours through SVG/DXF/paste);
- #1510 (LightBurn keys; bare PgUp/PgDn never move the machine);
- #1504 (rigid group rotation; remote array counts);
- #1513 (every e2e test change follows an intended product change; nothing was masked in the red window).

Also holding on their routes: #1500 (Marlin and network jobs stream off the window), #1499 (A1 Pro homing, CoreXY run-ups, `$$` read), #1506 (tabs through Delete node and Fillet) and #1509 (Studio scale fold and kept drawings).

**Tracer against Potrace 1.16.** Line Art 51 / 20 / 8, Sharp 49 / 22 / 8, Smooth 55 / 17 / 7 over 79 ground-truth images (was 27 / 19 / 33, 40 / 19 / 20, 27 / 17 / 35), confirmed with independent scoring. On real degraded images Smooth beats mkbitmap + Potrace 26 / 1 / 0.

**Where the P1s sit.** Two patterns:
- **Regressions introduced by the fixes (5):**
  - #1502 moves placed tabs on a rounded-rectangle resize (N3-P1-1);
  - #1507's migration shrinks older shrink-to-fit single-line text (N4-P1-1);
  - #1511 hides a second Fill operation's burn and paints captions under photos (N6-P1-1, N6-P1-2);
  - #1499 brings the A1 Pro under the every-connect detected-travel offer (N2-P2-1).
- **Sibling routes the fix did not reach (the rest):**
  - an unmatched Marlin echo (N1-P1-1);
  - lone full stops and the float i-dot floor (N8-P2-1, N8-P2-2);
  - GRBL Compatible Fill (N8-P2-5);
  - Optimize Shapes and the jig size field (N3-P1-2, N3-P1-3);
  - Bake, Production run and the jig text editor (N4-P1-2, N4-P1-3);
  - an Apply before a crash (N5-P2-2).

Each PR's own regression test covered only the exact case reported, so none of these was caught. Future fix briefs should ask for every route the report lists, plus one test per sibling.

**Fixed during the round:** N1-P1-1 and N1-P2-1 (#1515), N8-P2-1 and N8-P2-2 (#1516), N8-P2-3 and N8-P2-4 (#1517), N8-P2-5 (#1514), N3-P1-3 (#1518), N4-P1-2 and N4-P1-3 (#1519). Fix PRs are open for N2 (#1520), N5 (#1521), N3 tabs (#1522) and N4 frames (#1523); N6 has a fix card.

**Release exit (N7).** The first 1.0.28 release run's non-zero exit on a normal close has no cause found in KerfDesk's main-process code. That verdict is PLAUSIBLE; the harness did not record the code (N7-P3-2).
