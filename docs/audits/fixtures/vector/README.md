# Synthetic vector audit artwork

These eight `.lf2` files are ordinary project files derived from the repository's
`e2e/fixtures/project-basic.lf2` schema. They contain synthetic rectangles, open
contours, joinable lines, an opening, a dense near-straight path and an extension
boundary. They are intended for real File → Open interaction during the direct
computer-use audit; creating them is not evidence that a UI workflow passed.

All geometry is in millimetres. No machine connection, Frame, Start or output
execution is needed to use these files.
