## Round summary (2026-11-03)

All eight areas went through an auditor, a fresh refuter and a coordinator check in main's code: 90 findings raised, 3 refuted; **P1 3 / P2 16** (+1 KNOWN raised to P2) **/ P3 68**, plus 60 KNOWN re-observed.

**The headline.** A beginner who follows the screen can install KerfDesk, set up every simulated machine tried, make a design and complete a first burn; keyboard-only, small-laptop and phone users can always reach Start and Abort. What fails is what the beginner is never told: three P1s are wrong or lost results with no warning a beginner would understand, and most P2s are messages written for an expert.

**Top ten beginner blockers** (most likely to stop or spoil a first burn):

1. **U8-P2-1 (P1):** a stock-GRBL diode laser (`$32=0`) is set up as a CNC on first Connect; Start then fires `M3 S12000` with a 3 s dwell and unblanked travel, under spindle wording. Fix card proposed.
2. **U3-P2-2 (P1):** white parts of an imported SVG logo burn, twice. **Fixed by #1556.**
3. **U1-P2-3 (P1):** a returning beginner sees an empty canvas, and starting over makes the first design unreachable. Fix session running.
4. **U4-P2-1:** nothing before Start mentions glasses, fire or staying with the laser. Fix card proposed.
5. **U2-K:** no USB driver means an empty port list and silence on the web. Fix PR #1559 open.
6. **U2-P2-1:** Connect first, then pick the machine, kept the wrong command set (`$H` on an A1 Pro). **Fixed by #1558.**
7. **U2-P2-2 + U5:** raw `error:N` with "Check the Laser Log" (no such thing) on Home, jogs, Frame, Unlock and settings writes. Fix PR #1559 open.
8. **U4-P2-3 + U4-P2-5:** after Abort the origin is silently cleared, and after Unlock Frame dead-ends on "Wait for a complete status report". Fix card proposed (with U4-P2-4, Frame past the bed edge).
9. **U3-P2-4 + U4-P2-6:** a cut drawn first runs first, and expert notes bury the beginner's warnings in Job Review and Save G-code. Fix session running.
10. **U5-P2-1:** a grblHAL controller locked before connect is never offered Reset. Fix card proposed.

**Also open:** U1-P2-1 (Firefox/Safari not told the browser won't work; fix session running) and the three U7 P2s (live-region flood, welcome dialog focus, Job Review details by keyboard; fix card proposed). **Fixed during the round:** #1554 (U1-P2-2, U1-P2-4), #1555 (U3-P2-3), #1556 (U3-P2-2), #1558 (U2-P2-1).

**For the next round:** the cheapest single beginner aid is a Learn lesson that follows LightBurn's First Project page through to a finished burn (U8-P3-1), which is also the natural home for the safety, focus, starter-values and cut-last guidance. Fakes must set a controller's pre-connection state before the port opens (U5 refuter). Performance audit S1 resumes at S4 on the maintainer's word.
