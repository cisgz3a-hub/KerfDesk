## ADR-564 - Approved remote editing through MCP and a phone page

**Status:** Accepted for the initial integration requested by the maintainer on 2026-10-01. Remote customer/client qualification and publication are separate evidence.

**Context.** The maintainer requested both ChatGPT and other MCP clients, and a dedicated KerfDesk phone control page, to control the desktop workspace. The ordinary mobile product landing page remains the licence/download page; this separate control page does not mount a machining canvas.

**Decision.** An optional, initially disabled desktop connection uses an outbound authenticated WebSocket to a separate first-party Cloudflare Worker. SQLite Durable Objects coordinate one computer each. The maintained Cloudflare OAuth provider supplies MCP authorization, PKCE, audience/resource validation, token storage and discovery; a dedicated KV namespace is separate from the licensing Worker. MCP tools use the portable stable MCP TypeScript SDK. The phone page and MCP clients call the same bounded renderer commands.

Pairing requires a short-lived, one-use code and explicit approval on the computer. Each connection has viewing permission or viewing and editing permission; permission is checked on the relay and desktop. Credentials stay in operating-system secure storage, with no plaintext fallback. Disabling access closes the connection immediately and durably queues revocation before it can reconnect. Revoking a client cancels its outstanding commands. Desktop network traffic begins only after the trusted renderer opens behind the existing startup/first-use gates. Remote authorization never prevents ordinary workspace access or changes the licence contract.

The sandboxed renderer remains the authority for the live unsaved document. Main serves private same-origin routes with a renderer session identity. Replacement, closure, cancellation and disconnect invalidate outstanding work. Writes carry the last observed revision and a unique request ID. Local edits, Undo/Redo and Open/New change the revision. Duplicate IDs are bounded and fail closed rather than evicting records and replaying old mutations. Asynchronous text creation checks its exact document/revision owner before committing. Ordinary actions retain Undo and autosave behavior.

Initial tools read artwork/operation summaries, machine limits, edition/update status and material recipes. They select and transform existing artwork; create basic text and rectangles in Laser workspaces; and edit ordinary laser operation power, speed, passes and enabled state. CNC creation and CNC operation settings are outside this initial tool capability. Existing Pro artwork may be transformed under the existing editing contract; no Pro creation/copy path is exposed. Results are whitelisted, bounded and exclude licence/payment tokens, serial identities, native paths, camera credentials and source/artwork payloads. Workspace content supplied to clients is untrusted data, never instructions. Users are told that requests/summaries pass through Cloudflare and MCP clients may share them with their AI provider.

No shell, arbitrary file, console/G-code, machine connection, motion, spindle/laser, Frame or Start tool is exposed in this initial integration. Machine execution stays in the desktop operator workflow. The ordinary completed-Frame-only Start policy and Pro-tool admission are unchanged. A remote review reports unavailable unless the existing prepared-job authority supplies matching evidence; it cannot manufacture a completed Frame or readiness claim. No hardware qualification is implied by protocol, software or simulator checks.

**Consequences.** The computer must remain awake, online and running KerfDesk. Cloudflare plan/quotas and client eligibility require current primary/provider evidence. Standard MCP operation is distinct from ChatGPT public plugin review or mobile custom-client availability; a shipped endpoint does not prove those external outcomes. OAuth/KV provisioning, live pairing, protocol and actual desktop/phone-client evidence are required before claiming a deployed integration. There are no model API calls or bundled model API keys in this service.
