# ADR-653 Amendment 3: preserve workflow owners and displayed artwork

Date: 2026-10-23

Status: Implemented; verification is recorded in the linked remediation ledger.

The maintainer requested a fresh audit, repair, pull request and merge for the 34 findings from the four parallel interface, file/project, artwork/text and image/preview audits. The baseline is `8acc4599c918c3ab7dd4e9f625437cb2f22e3620`.

1. **Keep transient edits with their owner.** Numeric field drafts are retired when the selection or document changes. Duplicate and Paste clear old node references. Entered-group selection and layout tools share the current hierarchy scope. Joining paths repairs text-guide dependencies and retains authored names. Regenerating retained arrays preserves complete source groups and imports only generated instance groups.
2. **Claim asynchronous requests before waiting.** Recent and template opens reserve the same request ownership as ordinary Open. Separate PWA launches retain launch order. External opens recheck modal state at publication and offer the existing pending-open handover when a modal appeared during the read. Fallback readers and final PNG assembly honour cancellation before changing the document. Snapshot completion clears only the name it submitted.
3. **Publish current workstation evidence.** Recent file identity is checked against the snapshot committed by its transaction, retrying when another window changed the list. A name-only drop cannot inherit a different known file reference. A stale probe cannot replace newer evidence. Unpin and recording use the committed Keep limit, including changes saved by another window. The documented ADR-378 initial-storage-refusal duplicate exception remains unchanged.
4. **Commit what the editing surface represents.** Warp and Deform use the current materialised barcode geometry shown by the preview. Rigid text bending carries glyph contour ownership from font layout instead of inferring glyph identity from overlapping ink. Closed path guides contain no zero-length sampling steps. Copy Along Path uses the existing piecewise gap solver for unchanged-size copies too; its projected-gap metric is not general collision avoidance on folded or intersecting guides.
5. **Retain and cancel image work consistently.** Image Size couples both dimensions at their cap and clears obsolete crop coordinates on a real resize. Clone sources belong to their image session. Changing tools or sessions retires held pointer gestures synchronously, so Escape cannot resurrect an unfinished crop or stroke. Cursor colour information reads the displayed composite, including transparency and enabled adjustment previews.
6. **Keep ordinary controls usable.** Snap forms retain native Tab traversal. Overflowing notification stacks accept mouse scrolling and scrollbar input; fitting notifications keep the existing canvas click-through behaviour. Failed Auto-connect writes enter the existing settings warning/retry queue and retain the requested session value. Docked Console drafts and filters survive panel remounts in memory, without storing commands in projects or submitting them on restore.

These repairs change no Frame/Start, output, licensing, provider or hardware policy and add no dependency or project-format revision. Software checks and simulated/browser evidence do not qualify physical machinery, installers or deployments.
