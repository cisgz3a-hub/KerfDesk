# Machine and production tutorial accuracy audit

Date: 2026-09-19. Baseline: `189924b0f`, branch `codex/visual-tutorials-20260919`.

This is a source-backed instructional review of the 41 lessons listed below. It checks the described controls, workflow order, output scope and selected diagrams against the implementation and governing operator contract. It does not establish hardware, material, controller, packaged-runtime or machining qualification, and does not assert that every possible workflow has been exercised.

## Verification and remaining gaps

- Prettier and scoped ESLint were run for the changed machine/production content and diagrams. The new production scene module is below the repository's 400-line ceiling.
- Pure lesson objects and SVG scenes do not import machine actions, move hardware, change route state or mutate the working project. The examples explain user actions; clicking through the tutorial is not an execution path for those actions.
- Generated photography and its delivery/rendering are being handled in the integrating task. A generated photograph is illustrative, not evidence of actual output. For the leather jig image, the outline should be a rectangular bounding outline to match the current jig generator.
- This pass does not prove every illustration, calibration result, cutter compensation, controller protocol, feed/power recipe or material result. The scoped corrections above address confirmed mismatches; other lesson coverage is source review, not full end-to-end execution.
- No physical cut, burn, air-cut, probe, Frame, Start, camera calibration or stock indexing was performed. Machine qualification and the complete integrated UI checks remain separate evidence.
