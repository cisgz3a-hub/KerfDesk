Linux AppImage runtime and libraries

Only the Linux .AppImage download carries the components below. They are not
npm packages: electron-builder 26.17.0 adds them from its AppImage toolset,
electron-userland/electron-builder-binaries release appimage@1.0.3, file
appimage-tools-runtime-20251108.tar.gz (SHA-256
84021a78ee214ae6fd33a2d62a92ba25542dd10bc86bf117a9b2d0bba44e7665). KerfDesk's
own code does not link, import or call any of them (ADR-017 Amendment 1).
The full LGPL-2.1 text follows this section.

1. The AppImage runtime. This is the small program at the start of the
.AppImage file. It mounts the compressed image through FUSE and then starts
the AppRun launcher; it is a separate executable, not part of KerfDesk or
Electron. It is AppImage type2-runtime release 20251108 (runtime-x86_64),
built on Alpine Linux 3.21 and statically linked with libfuse, squashfuse,
Zstandard, zlib, musl libc and mimalloc. Complete source of the runtime, the
libfuse patch and the build scripts:
https://github.com/AppImage/type2-runtime/tree/dd6cebedcbddde9c82f89b011e8e1d40b6e43868

3. Shared libraries in usr/lib. electron-builder copies these Ubuntu 18.04
builds from the same toolset into the AppImage's usr/lib folder, and AppRun
puts that folder on the library search path. They are unmodified. Each one's
source is the Ubuntu 18.04 (bionic) source package named, at
https://launchpad.net/ubuntu/bionic/+source/<source package>. The toolset also
holds libgconf-2, libappindicator3 and libindicator3; KerfDesk's build leaves
them out, so the AppImage does not carry them (ADR-017 Amendment 2).
