    Each signed manifest binds filenames, sizes and SHA-256 digests to a version and source revision. It proves the publisher approved these bytes; it is not an operating-system code signature, notarization, or an independent GitHub build attestation for private source.     Install an unsigned Preview

    These steps are for Preview. KerfDesk for Windows has its own steps above.

    Windows SmartScreen

    1. Run the downloaded setup file.
    2. Only continue if it came from the verified Preview links above and its filename contains -preview. followed by a number.
    3. If SmartScreen shows Windows protected your PC, select More info.
    4. Confirm the publisher is shown as unknown, then select Run anyway.

    macOS Gatekeeper

    1. Open the DMG and drag KerfDesk.app to Applications.
    2. Control-click KerfDesk.app in Applications, choose Open, then choose Open again.
    3. If macOS still blocks it, open System Settings > Privacy & Security and choose Open Anyway.

    Mac Preview builds are both unsigned and unnotarized. KerfDesk does not disable or silently bypass Gatekeeper.
