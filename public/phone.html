FIRST CONNECTION

Start on your PC

Three steps to connect.

  1. Enable access in the desktop app

    In KerfDesk on your PC, open Edit → Settings… → Phone & MCP. Enable Allow approved remote connections and wait for Ready to pair (older versions say Connected to the remote service).

    Keep KerfDesk open and the computer awake and online. If Phone & MCP is missing, get the current Windows app. Save your project and close the app before installing an update.

  2. Enter the code on your phone

    Click Create pairing code on the PC. Open the phone control page, enter the Computer ID and Pairing code shown on the PC, and name your phone. Select Request PC approval.

    Copy the code exactly: letter case matters. Match the Computer ID to the same open PC. A code works once and expires after five minutes. Create a separate code for each new connection.

  3. Approve this phone on the PC

    Check the phone’s name in the desktop approval prompt, then choose Allow viewing, or select the requested editing and machine-control choices and Approve selected access. Both choices start off. The phone page opens the approved workspace.

    Revoke a connection any time from Phone & MCP in desktop Settings. Turning remote access off disconnects clients immediately.

Machine control needs its own PC approval. Approved connections can Jog, Frame, review the job, Start and Abort through the desktop. These controls require a desktop release and service that support them; existing viewing/editing approvals gain no motion access. This phone page keeps the design canvas on your computer. Remote access does not activate Pro or use a licence seat; the app’s existing Pro tool rules still apply.

Help with your connection.

There is no approval prompt on my PC.

Check that remote access is on and the PC says Ready to pair (or Connected to the remote service in older versions). Match the Computer ID and copy the code exactly, including capital letters. Keep the desktop app open while you request approval. If the phone reports that pairing is unavailable, create a new code and retry. If a new code still fails, use KerfDesk support and describe the status on both devices. Do not share your pairing code or licence key.

How do I connect ChatGPT or another MCP app?

In ChatGPT on the web, enable Developer mode under Settings → Security and login, then create an MCP connection in Plugins. Choose OAuth authentication and let ChatGPT discover the sign-in settings.

Use this server address in a client that supports authenticated remote MCP servers: https://kerfdesk-phone-control.cisgz3a.workers.dev/mcp Create a new pairing code on the PC, enter the Computer ID and code on the client’s sign-in page, then approve its requested access on the PC.

In Advanced OAuth settings → Base scopes, add kerfdesk:edit for artwork editing and kerfdesk:control for machine controls, then explicitly approve those choices on the PC. The default kerfdesk:read scope allows viewing. You do not need an OpenAI API key.

ChatGPT custom connections depend on your plan, workspace and available client features. This setup does not claim availability in every ChatGPT mobile app or a public plugin listing. The phone control page works in an ordinary supported browser.

Where do my phone requests go?

Approved requests and workspace summaries pass through KerfDesk’s Cloudflare remote service. An MCP client may also send them to its AI provider. Licence keys, serial ports and saved file paths are excluded. Read the privacy notice for session and retention details.
