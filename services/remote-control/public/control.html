Connect to your computer

  1. Open Settings → Phone & MCP on your PC and enable remote connections.
  2. Wait for Connected to the remote service, then create a pairing code.
  3. Enter the same computer ID and latest code below, including capitals in the code.
  4. Approve this phone on the PC.

The code expires after five minutes and works once.
